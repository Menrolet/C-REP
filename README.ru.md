# Сборник задач

В репозитории собраны небольшие упражнения на C/C++, каждое в своей папке.

- **Схема метро** (`metro_stations/metro_stations.c`): описывает граф метро, содержит `set_station_links` и `find_path` (BFS) для построения кратчайшего маршрута между станциями.  
  Пример сборки: `gcc metro_stations/metro_stations.c -std=c11 -Wall -Wextra -o metro && ./metro`

- **Стек URL** (`url_stack/url_stack.c`): односвязный стек посещений с функциями `push`/`pop`; в `main` добавляются заданные ссылки и освобождается память (без вывода).

- **Паттерн Singleton** (`singleton_pattern/main.cpp`): простая реализация ленивого синглтона, возвращает один и тот же указатель и выводит подтверждение.

- **Односвязный список** (`singly_linked_list/main.cpp`): список на `shared_ptr` с функциями `push_back`, `pop_front` и `show`; в `main` добавляются значения 1..4 и выводятся.

- **Расстановка мин** (`mines_placement/main.c`): размещает 12 мин (`*`) на поле 10x10 так, чтобы мины не соприкасались по сторонам и диагоналям; пустые клетки остаются нулями. Вывода нет.
